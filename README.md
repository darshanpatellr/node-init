# Node.js Course

## Home
Welcome to the Node.js Course! This repository contains 18 modules that will guide you through the fundamentals and advanced concepts of Node.js.

## Intro
Node.js is an open-source, cross-platform runtime environment that allows you to run JavaScript on the server side.

## Requirements
Before starting the course, ensure you have:
- Node.js installed on your machine
- Basic understanding of JavaScript

## Request API
Learn how to handle API requests and responses using Node.js.

## Event Loop
Understand the event-driven architecture of Node.js through the event loop.

## Asynchronous
Explore asynchronous programming concepts and patterns in Node.js.

## Promises
Dive into promises and how they simplify asynchronous programming.

## Async-Await
Learn to work with async/await for better readability and cleaner code.

## Errors
Grasp error handling techniques in Node.js applications.

## Modules
Understand how to organize your code with modules in Node.js.

## ES-Modules
Explore ES6 modules and how they are implemented in Node.js.

## npm
Learn about npm and how to manage your packages efficiently.

## HTTP-Module
Understand how to create HTTP servers and clients with the HTTP module.

## HTTPS-Module
Learn about secure server/client communication using the HTTPS module.

## File-System
Explore file system operations like reading and writing files.

## OS-Module
Understand how to interact with the operating system through Node.js.

## URL-Module
Learn how to parse and format URLs in Node.js.

## Events-Module
Explore the events module and the observer pattern in Node.js.
